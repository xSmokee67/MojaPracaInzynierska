# Frontend – Hotel Resort

Aplikacja React (JavaScript, JSX) budowana przez Vite, style w Tailwind CSS. Opis całego projektu, architektury i uruchomienia: [README.md](../README.md) w katalogu głównym.

## Polecenia

W katalogu `Frontend`:

| Polecenie | Działanie |
|-----------|-----------|
| `npm install` | instalacja zależności (katalog `node_modules`) |
| `npm run dev` | serwer deweloperski z odświeżaniem na żywo: `http://localhost:5173` |
| `npm run build` | wersja produkcyjna w katalogu `dist` |
| `npm run preview` | podgląd wersji z `dist` |
| `npm run lint` | sprawdzenie kodu przez ESLint |

Adres API ustawia plik `.env` (`VITE_API_URL`).
